# Общие настройки Held / IK

1. Выберите один или несколько ассетов `ItemDefinition` — например редкие варианты сабли, без обычного варианта.
2. В инспекторе откройте раздел **«Общий профиль Held / IK»**.
3. В поле **«Базовый предмет»** назначьте обычный вариант сабли.
4. Дальше редактируйте Held и IK у обычного варианта: все связанные предметы получают его изменения автоматически, включая уже экипированные предметы в Play Mode.

Наследуются позиция, поворот и масштаб удержания, поза блока/прицеливания, включение и точки обеих рук. Если базовый предмет использует `ItemHandGripPoint` в prefab, используются его маркеры, переведённые в систему координат модели варианта. При замене маркеров prefab переэкипируйте предмет; значения IK в самом `ItemDefinition` читаются каждый кадр.

Редкость, урон, тип оружия, иконка, модель, положение предмета на земле и точка выстрела остаются индивидуальными.

У связанных предметов отображаются настройки источника с запретом редактирования и кнопка **«Открыть источник Held / IK»**. Собственные настройки вариантов не перезаписываются. Очистка поля или **«Вернуть собственные Held / IK»** восстанавливает их прежние значения. Назначение поддерживает Undo/Redo.

Цепочки профилей допустимы; замкнутые ссылки и назначение предмета самому себе запрещены. Это наследование по ссылке, без фоновой массовой перезаписи ассетов.
