# Интерфейс и настройки боя

**Общий префаб: `Resources/UI/GameUI.prefab`.** Перетащите его на сцену.
`HUD`, `Menus`, `World`, `Elements` и `Loading` — обычные дочерние группы.
Для просмотра включайте нужные объекты галочками в Hierarchy, как любой другой UI.
Отдельных режимов предпросмотра, скрытого `Templates` и контейнера копий `Live UI` нет.

Редактируйте GameUI или исходный вложенный префаб: размер, расположение, шрифт,
цвет, спрайты. Обычные связи Unity Prefab сохраняются. Изменения экземпляра на сцене
сохраняются в префаб через Overrides → Apply; отдельное переопределение на экземпляре
можно сбросить через Revert, чтобы он снова наследовал это свойство из префаба.

В игре используется размещённый на сцене GameUI. Если его нет, он загружается
автоматически. HUD и меню работают прямо на его дочерних объектах; при смене игрока
они переиспользуются. Копии создаются только для повторяющихся строк и индикаторов
объектов мира. `GameUiRoot` на корне — привязка к игре, оставьте этот компонент.
Во время игры показом окон управляют игровые события; в редакторе скрипты их не меняют.

Все окна находятся здесь. `Resources/UI/HUD` — игровой HUD; `Menus` — меню, гардероб,
прокачка, кольца и итог плавания; `World` — подсказки и индикаторы в мире;
`Elements` — повторяемые строки. Загрузочная шторка находится в `Loading`.

`Resources/UI/HUD/Stamina.prefab` — отдельная полоска стамины. Размер и положение
задаются на `Stamina`, обычный цвет и спрайт — на `Stamina fill`. На корневом
компоненте `StaminaBarView` настраиваются порог и цвет низкой стамины.
`Equipment.prefab` содержит только подсказку текущего инструмента.

`HUD/Inventory.prefab` содержит 10 ячеек с иконками из `ItemDefinition.Icon`.
Клавиши выбора — 1–9 и 0. Колесо вниз выбирает ячейку справа, вверх — слева;
выбор замыкается в круг и блокируется при открытом меню или переноске сундука.
Q выбрасывает один предмет из выбранной ячейки, а при переноске сундука кладёт его.
Панель `Drop Hint` в левом нижнем углу настраивается прямо в `HUD/Inventory.prefab`.
У каждой ячейки `InventorySlotView`: `Selected Scale` задаёт увеличение (1.14),
`Scale Speed` — скорость перехода (16). Цвет рамки при выборе не меняется.
Рамки, фон, значок клавиши и текст количества редактируются внутри `Visual`.
Иконки назначены предметам в каталоге; любую можно заменить в поле `Icon`.

HP и стамина находятся рядом над слотами: `HUD/PlayerHealth.prefab` и
`HUD/Stamina.prefab`. Размер и позиция задаются на `Health Frame` и `Stamina`.
Все три Canvas используют одинаковые Reference Resolution (1920×1080) и Match (0.5).

Откройте prefab и изменяйте RectTransform, шрифт, размеры, Image/sprite и оформление.
Runtime загружает эти префабы, не перестраивая их оформление. Имена служебных дочерних
объектов используются для привязки данных — сохраняйте их при редактировании дизайна.
Цвет имени предмета/кольца и фона его иконки задаётся редкостью; значения и заполнение
полос обновляются игрой. `Elements/RingRow` используется и в выборе, и в меню Tab.

Настройки:

- `Assets/_Project/Resources/PlayerRingCatalog.asset`: лимит разных колец
  `MaximumDistinctRings` (сейчас 4), имена, иконки, бонусы и веса редкостей.
  Если все слоты заняты, предлагаются только улучшения имеющихся колец.
  Окно выбора остаётся открытым до выбора всех участников заплыва. Отключившиеся
  игроки исключаются из ожидания. Новые подключения разрешены только в порту:
  при отправлении сервер закрывает вход и Steam-лобби, после загрузки порта открывает.
- `Assets/_Project/Resources/DamagePopupSettings.asset`: Font, FontStyle, размер,
  цвет, обводка, время жизни, скорость подъёма, дробные знаки, дальность и лимит цифр.
  Попапы используют NativeArray, Burst/Jobs и один общий меш; нет GameObject на попадание.
  Лимит по умолчанию — 2048: при превышении заменяются старейшие цифры.
- `Assets/_Project/Resources/NightWaveSettings.asset`: `FogFadeInSeconds`, `FogFadeOutSeconds`,
  `FogImmersionDistance`, форма, цвета, шум и радиус каждой волны.
  Точка зоны фиксируется при начале волны. При входе в туман круговая граница
  визуально растворяется. Дневной спавн островов и плавающего лута приостановлен
  на время боя; предметы, полученные игроком из сундуков и с врагов, остаются наградами.
  После окончания волны туман плавно исчезает (по умолчанию за 4 секунды),
  а урон за выход из зоны прекращается сразу. Последний центр зоны сохраняется на время затухания.
- `Assets/_Project/Resources/OceanGeneration.asset`: `IslandRevealRadius` — появление,
  `IslandHideRadius` — скрытие уже увиденного острова, `IslandRemovalRadius` — удаление,
  `MaximumResidentIslands` — бюджет. При заполнении бюджета близкие острова сохраняются,
  генерация ждёт освобождения места. Поворот корабля сам по себе остров больше не удаляет.
- `Player.prefab / NetworkPlayerController`: базовый ближний/дальний урон.
  Итог: `(базовый урон персонажа + Potency оружия × множитель редкости) × бонус колец`.
  Множители оружия: 1 / 1.25 / 1.6 / 2 / 2.5. Подсказка показывает итог для местного игрока.
- `Player.prefab / PlayerEquipment`: `Burst Shot Interval` — пауза между снарядами;
  скорость атаки уменьшает её. Переключение оружия/смерть отменяет остаток очереди.
- `ShipCannon.prefab / ShipCannon / Recoil`: дистанция отката, время удара и возврата.
  Откат визуальный и не смещает расчётную траекторию снаряда.

Проверки без входа в Play Mode:
`Tools → Wave by Wave → Checks → Waves weapons rings and UI`.
