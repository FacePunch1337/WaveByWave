# Запекание иконок предметов

Окно: **Tools → Wave by Wave → Items → Icon Baker**. Его также можно открыть
кнопкой в Inspector любого `ItemDefinition` или через контекстное меню Project.

1. Выберите предмет. Модель берётся из его `World Visual Prefab`.
2. Задайте `Поворот модели, °` по X/Y/Z. Кнопка **Обратная сторона** добавляет
   180° по Y; **Влево 90°** и **Сброс поворота** помогают быстро выбрать ракурс.
3. Настройте удаление фона, обрезку, отступ и яркость по образцу в окне.
4. Для предмета с готовой иконкой включите **Заменять существующие иконки**.
5. Нажмите **Запечь предмет**. Готовый Sprite назначится в `ItemDefinition.Icon`.

Можно обработать выделенные предметы или весь каталог. Текущие настройки,
включая поворот, применяются ко всей выбранной группе. По умолчанию предметы
с заполненным Icon пропускаются. Остановка сохраняет уже готовые результаты.

Новые иконки сохраняются в `Assets/_Project/Prefabs/UI/Art/ItemIcons`.
Каждый новый файл `.asset` содержит Sprite и его текстуру. При включённой замене
существующий native Sprite `.asset` обновляется на прежнем месте, даже если его
текстура хранится отдельным `.asset`. Ссылки сохраняются. Если Sprite используется
в нескольких местах, новое изображение появится во всех этих местах.
Папка вывода применяется к новым иконкам. Исходные PNG и области атласов не
перезаписываются: для них создаётся отдельная иконка, назначаемая предмету.
Кнопка экспорта сохраняет показанный образец в PNG без назначения его предмету.

Ячейки Inventory в общем GameUI ссылаются на те же Sprite, что и соответствующие
предметы. После перезапекания новые изображения видны в префабе и на сцене до запуска.
Дополнительных скриптов предпросмотра для этого нет. Кнопка **Показать текущую иконку
в Project** находит фактически используемый ассет.

Используется штатная миниатюра Unity AssetPreview; исходное разрешение показано
под образцом. Это инструмент для небольших иконок инвентаря. Для поворота создаётся
временная копия статических мешей и материалов без игровых компонентов.
Исходный prefab, сцена, камеры, освещение и префабы UI не редактируются.
Временная геометрия удаляется при смене ракурса, завершении запекания или закрытии окна.

Если фон остался в ручке предмета, включите **Фон внутри отверстий**. Если пропали
серые детали модели, отключите эту опцию или уменьшите допуск фона.
Модель лопаты сейчас условная: её миниатюра показывает именно эту простую геометрию.

Проверки обработки, сохранения ссылок и пакетной очереди:
**Tools → Wave by Wave → Checks → Item icon baker**.
