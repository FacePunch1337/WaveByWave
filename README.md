# Wave by Wave

Первый вертикальный срез кооперативного пиратского roguelike для Unity 6.

## Получение проекта

Нужны Git, [Git LFS](https://git-lfs.com/) и Unity **6000.2.8f1**.
Перед клонированием установите Git LFS:

```sh
git lfs install
git clone https://github.com/FacePunch1337/WaveByWave.git
cd WaveByWave
git lfs pull
```

Добавьте папку проекта в Unity Hub и откройте её указанной версией редактора.
При первом запуске Unity восстановит пакеты и импортирует ресурсы.
Встроенный пакет `Packages/com.unity.netcode.gameobjects` хранится в репозитории.

Бинарные ресурсы и большие сгенерированные меши хранятся через Git LFS.
Файлы `.meta`, сцены, префабы, исходный код и настройки проекта также включены
в репозиторий. Кеши Unity, локальные сборки и выходные данные `DeltaServer`
исключены через `.gitignore`.

## Что уже работает

- `Port` — стартовая сцена с простым портом, точками будущей мета-прокачки и сетевым меню.
- Steam lobby/invite через Facepunch transport; при недоступном Steam автоматически включается локальный host.
- Owner-authoritative Rigidbody-перемещение игрока, NGO-интерполяция удалённых тел и синхронизация параметров анимации.
- Owner-камера хранится в неактивном `Camera Holder` внутри `Player.prefab` и включается только у локального владельца.
- Инвентарь на 8 слотов со стартовыми предметами: сабля, мушкет, крюк, ведро и лопата.
- Выбрасывание и подбор сетевых предметов.
- `Ocean` со Stylized Water 3 и Underwater.
- Сетевой корабль-заглушка, штурвал и общая система `MovingPlatform`: стоящий игрок фиксируется в локальной точке любой сетевой движущейся платформы, а при прыжке наследует линейную и угловую скорость точки отрыва.
- Физический корень игрока остаётся в world space, а камера и модель отображаются в системе координат опоры. Поэтому интерполяция платформы и игрока не создаёт визуального скольжения у клиентов.
- Штатный `StylizedWater3.AlignToWater` установлен прямо на корневом сетевом корабле. Высота и наклон рассчитываются только сервером и синхронизируются через NGO вместе со всем корпусом и коллайдерами.
- `Physics Auto Sync Transforms` включён, чтобы сетевое положение коллайдера движущейся опоры было доступно Rigidbody-мотору клиента в том же кадре.

Чтобы новая движущаяся платформа получила ту же компенсацию, её сетевой корень должен содержать `NetworkObject`, `NetworkTransform` и `MovingPlatform`; коллайдеры могут находиться на любых дочерних объектах этого корня.
- Начальная граница NGO/ECS: NGO отвечает за сессию, игроков и интеракции; массовая симуляция зарезервирована за Entities/Netcode for Entities.

## Управление

- Вид строго от первого лица; мышь управляет взглядом и поворотом персонажа.
- `WASD` — движение относительно взгляда; `Shift` — спринт; `Space` — прыжок.
- `E` — взаимодействие; у штурвала `W/S` задают ход, `A/D` поворачивают, повторный `E` отпускает штурвал.
- `1–8` — слот инвентаря; `ЛКМ/ПКМ` — основное/специальное действие; `G` — выбросить предмет.
- `Esc` — сетевое меню, приглашение Steam и переход из порта в море.

## Структура

- `Assets/_Project/Runtime/Core` — composition root и реестр зависимостей.
- `Assets/_Project/Runtime/Networking` — сессия, Steam/local transports и spawn flow.
- `Assets/_Project/Runtime/Player`, `Items`, `Ships`, `UI` — игровые feature-модули.
- `Assets/_Project/Runtime/Simulation` — граница GameObject-сети и DOTS-симуляции.
- `Assets/_Project/Editor` — генератор и валидатор вертикального среза.

Для пересоздания прототипа: `Tools > Wave by Wave > Regenerate Vertical Slice`.
Для проверки: `Tools > Wave by Wave > Validate Vertical Slice`.

## Генератор коллизии меша

`Tools > Wave by Wave > Physics > Generate Mesh Collision` создаёт коллизию для выбранного `MeshFilter`
или выбранной иерархии. Режим `Exact Dynamic Surface` превращает каждый треугольник исходного меша в тонкую
convex-призму, направленную внутрь объекта. Поэтому внешняя контактная поверхность точно совпадает с мешем и
остаётся допустимой для динамического `Rigidbody`. Этот режим требует правильного направления треугольников
и создаёт один PhysX shape на треугольник, поэтому предназначен для случаев, где точность важнее стоимости.

Более быстрый `Compound Convex` разбивает поверхность на небольшие convex hull и приближённо сохраняет
вогнутые детали. Старые `MeshCollider` отключаются без удаления и восстанавливаются кнопкой удаления
сгенерированной коллизии.

Режим `Exact Static` создаёт единый точный concave-коллайдер и предназначен только для статических объектов
или `isKinematic` Rigidbody: PhysX не поддерживает такой коллайдер на динамическом твёрдом теле.
