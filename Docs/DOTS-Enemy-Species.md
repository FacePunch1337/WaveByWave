# Тролль, акула и земноводный

Все три вида используют те же серверные ECS-состояния, сетевые ghosts, урон, оглушение, выпадение добычи и GPU-анимацию, что и скелеты. В игре у отдельного врага нет Animator, SkinnedMeshRenderer или собственного Update. Случайные модули внешности и выбор оружия для новых видов выключены.

## Проверить в игре

На хосте откройте **F2**. В начале прокручиваемого списка находятся кнопки создания тролля, акулы и земноводного по **1** или **10**. Ползунок **«Радиус врагов»** задаёт область вокруг игрока. Для акулы в этой области должна быть достаточно глубокая открытая вода; при отсутствии подходящих точек спавн пропускается с сообщением в Console. Троллю нужна суша или палуба.

В этом же списке есть переключатель **«HP-бары: ВКЛ/ВЫКЛ»** для каждого вида, включая обычных скелетов, и удаление тестовых новых врагов. Переключатель распространяется на существующих врагов выбранного вида и следующие спавны.

Для расстановки на сценах используйте `Assets/_Project/Prefabs/Enemies/Species/TrollSpawn.prefab`, `SharkSpawn.prefab` и `AmphibianSpawn.prefab`. Компонент `EnemySpawnPoint` поддерживает вид врага, количество, радиус, активацию по приближению и отдельный режим HP-бара.

## Настройки

Профили находятся в `Assets/_Project/Resources/Enemies/`:

| Профиль | Поведение | Начальные HP / урон |
|---|---|---|
| `TrollEnemyCatalog` | Наземный сильный тролль с исходными анимациями | 400 / 38 |
| `SharkEnemyCatalog` | Плавает в воде, атакует находящихся в воде игроков | 160 / 28 |
| `AmphibianEnemyCatalog` | Один скелет без одежды и оружия, ходит, проходит мелководье и плавает | 90 / 16 |

Основные поля: `Maximum Health`, `Melee Damage`, `Move Speed`, `Swim Speed`, `Melee Range`, `Melee Cooldown`, `Visual Scale`. После изменения масштаба модели согласуйте `Body Height`, `Body Radius` и `Projectile Hit Radius` с её размером. У акулы дополнительно задана горизонтальная капсула попаданий (`Custom Hit Capsule`, `Hit Capsule Start/End`).

`Swimming Depth` задаёт глубину **начала координат модели** относительно уровня океана. `Minimum Water Depth` ограничивает спавн и движение акулы на мелководье. Земноводный может идти по неглубокому дну, чтобы переход между водой и сушей оставался непрерывным. Внутренняя вода корабля не используется для плавания ботов. Акулы не проходят через сушу; земноводные выходят на достижимый берег, но не телепортируются через стену корпуса.

Общий лимит врагов, бюджет проверки поверхностей за кадр, слои поверхностей и настройки обхода толпы по-прежнему берутся из `SkeletonEnemyCatalog`. Виды разделяют этот бюджет. Физические проверки воды выполняются только для очередной порции врагов; отдельного NavMesh для акул нет.

## HP-бары

По умолчанию выключены во всех четырёх профилях. Включение:

- `Show Health Bars` в профиле — для всего вида, если спавнер использует `Profile`.
- `Health Bar = Show` в конкретном `EnemySpawnPoint` — только для созданной им группы; `Hide` принудительно скрывает.
- Переключатель в F2 — тестовое серверное переопределение, передаваемое клиентам.

`Health Bar Height`, `Health Bar Size`, `Health Bar Distance` настраивают высоту, размер и дальность. Цвета находятся в материале, вложенном в `Assets/_Project/Data/Enemies/Species/HealthBar.asset`. Для отдельных цветов вида можно назначить ему отдельный материал с шейдером `WaveByWave/EnemyHealthBar`.

Полоски — ECS-меши, повёрнутые к камере, с глубиной сцены. У выключенных полосок нет визуальных entities; у включённых они создаются только в пределах заданной дальности. Canvas на каждого бота не создаётся.

## Риги и запекание

Исходники для редактирования:

- Тролль: `Assets/Troll_Сannibal/Prefabs/Troll_cannibal.prefab`, клипы `idle battl`, `run`, `attack 1` из его FBX.
- Акула: `Assets/_Project/Prefabs/Enemies/Species/SharkRig.prefab`, 7 костей с плавными весами. Клипам `SharkIdle.anim`, `SharkSwim.anim`, `SharkBite.anim` соответствует боковая волна изгиба с нарастающей амплитудой к хвосту. Клипы находятся в `Assets/_Project/Data/Enemies/Species/`.
- Земноводный: `Assets/_Project/Prefabs/Enemies/Species/AmphibianRig.prefab`, очищенная копия `skeleton_01`. Использует generic-клипы скелета, включая `pirate_swim`.

Чтобы заменить риг земноводного, назначьте новый prefab в `Baking Rig Prefab` и единственный `Part Sources / Body`, задайте подходящие **Generic**-клипы того же рига и нажмите **Bake prefab meshes and animation textures** в инспекторе профиля. Данные находятся в `Assets/_Project/Data/Enemies/Species/<вид>/`. GUID существующих запечённых ассетов сохраняются. Игровая модель использует именно эти меши и текстуры, поэтому изменение исходного клипа требует нового запекания.

Команда **Tools → Wave by Wave → Enemies → Create and bake troll, shark and amphibian** создаёт отсутствующие профили и затем запекает их. Настроенные профили и существующие исходные риги не пересоздаёт. Перед сборкой устаревшие данные запекаются автоматически. Для ручных правок клипов до Play используйте кнопку запекания в профиле.

## Проверки

Команда **Tools → Wave by Wave → Enemies → Validate new species and render animations** проверяет фиксированную внешность, движение вершин, размеры мешей, шейдеры, капсулы попаданий, выбор целей и переход земноводного через тестовый берег в обе стороны. Проверяется также запрет спавна/движения акулы на суше. Временная тестовая сцена закрывается после проверки, открытые пользовательские сцены сохраняются. Отчёт: `Temp/EnemySpecies.result`; кадры GPU-анимаций: `Temp/EnemySpecies.png`.

Это проверки в редакторе; поведение при задержках сети и нагрузку большой смешанной толпы нужно оценивать в игровом тесте хост + клиент.
